Sobre Mim

Sou estudante de Análise e Desenvolvimento de Sistemas pela UNOPAR e moro no Rio de Janeiro. Tenho aprendizado rápido, gosto de resolver problemas e de transformar ideias em soluções funcionais, de sistemas web e dashboards de dados a automações e jogos.

Tenho experiência prática em suporte de TI e em sistemas de PDV, além de projetos próprios com HTML, CSS, JavaScript, Python e Java. Também trabalho com bancos de dados, Git e GitHub, e tenho inglês fluente (C1).

Minha formação inclui cursos de Análise de Dados com Python, IoT e Programação de Sensores, Desenvolvimento Full-Stack em Java e Git e GitHub. Busco uma oportunidade para contribuir com projetos desafiadores e continuar evoluindo profissionalmente.
